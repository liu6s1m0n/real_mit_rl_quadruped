# 2026-10-29 单次踏步支撑力链路复核

本轮按用户确认的当前机器 **14 kg+** 分析。使用配置中的 14.705035 kg 作为计算基准，
重力为 9.81 m/s²，静态竖直支撑需求为 **144.26 N**，均分到两条支撑腿约为 **72.13 N/腿**。
11.8 kg 是此前对照条件，不再用作当前实机的支撑需求基准。

结论：已有证据支持“模式切换后，支撑腿接管负载过慢”这一具体问题。
当前 0.20 s 输出混合会把原来四腿支撑的力矩带入两腿支撑初期；
WBC 算出的两腿支撑解没有立即完整进入电机指令。
同时，起步姿态的质心投影偏离对角支撑线，增加竖直力总和不能单独消除倾覆趋势。
这些结果尚不足以确认电机失能保护的唯一触发原因。

## 从 MPC 到发送指令的检查

`src/control/opendog_algorithm.cpp` 在 WBC 求解后还会对关节位置、速度和前馈力矩同时混合：

```text
输出 = (1 - alpha) × 切换前最后指令 + alpha × 当前新指令
alpha = (当前时间 - 切换开始时间) / phaseTransitionStanceTime
```

原参数为 0.20 s。在混合开始时，支撑腿仍接近四腿支撑时的负载；
而 WBC 的无接触力约束和基座动力学已经按两腿支撑求解。
位置和速度也一起混合，因此不能只从 WBC 日志判断电机正在执行其支撑解。
该参数还用于原有 `GaitSchedule` 的支撑过渡，本轮没有把它误当成仅控制输出混合的独立参数。

用最新实测 IMU、q、dq 按记录时间离线回放，保留原始 MPC/WBC 路径，
仅在 `/tmp` 的独立可执行文件中记录混合前后量。按模式切换时刻对齐，保护前结果如下：

| 切换后时间 | MPC 两支撑腿 Fz 合计 | WBC 两支撑腿 Fz 合计 | 混合输出的等效 Fz 合计 |
| --- | ---: | ---: | ---: |
| 0–50 ms | 144.9 N | 147.6 N | 83.6 N |
| 50–100 ms | 142.3 N | 150.2 N | 103.1 N |
| 100–150 ms | 143.2 N | 154.6 N | 124.6 N |
| 150–200 ms | 141.2 N | 147.2 N | 137.8 N |

“等效 Fz”固定当前 WBC 的广义加速度，用实测姿态的足端雅可比和
`F_equivalent = F_wbc + J_joint^(-T) × (tau_wbc - tau_output)` 计算，
用于隔离输出混合造成的关节力矩变化；它不代表机器人实际具有这份地面反力。
改变电机输出后，实际加速度、接触状态和浮动基座平衡也会变化。
回放采用异步 MPC，独立运行间策略更新时刻存在小幅差别，因此表中数值取近似值。

保护前 11.35–11.65 s 内，CSV 的最大预计关节总力矩约 **23.60 Nm**，
发布的 KP/原 KP 最小比例为 **1.0**。本次窗口没有 88 Nm 软件总力矩限幅导致的支撑削减证据。
WBC 的 97 Nm 约束与电机自身电流、温度、电压等保护不是同一个机制，当前日志未记录完整故障码。

WBC 原权重是摆腿 100、基座加速度 1、接触力 0.01；`Task` 先按权重缩放残差，
QP 再平方，接触力跟踪是软目标。离线尝试提高接触力权重至 0.1/1 可以改变 WBC 跟踪误差，
但保留 0.20 s 输出混合时，前 50 ms 等效支撑仍约 83 N，没有消除加载延迟。
本轮因此未固化 WBC 权重改动。

## 支撑几何

使用现有 MJCF 的质量分布、最新 CSV 的关节角和 IMU 姿态做运动学计算：

- 起步前约 11.35 s，质心投影距离 FL–RR 支撑线约 **33.2 mm**。
- 重力绕这条三维支撑线产生约 **4.79 Nm** 的力矩。
- 当前名义站姿的对应重力力矩约 **3.31 Nm**，说明对角支撑并非天然静力平衡。

这项计算假设实物质量分布与当前模型一致。两点接触的合力不能提供任意支撑力矩；
需要合理的质心运动和落脚配合。当前观察到的偏差属于后续应继续验证的控制问题，
本轮没有修改站立姿态或增加自动取消、回退、拒绝计算逻辑。

## 参数对照与固化

为直接检查支撑接管，用现有 MuJoCo 单次踏步测试运行原配置与隔离候选配置。
额外通过 `mj_contactForce()` 读取足底接触力，并变换到世界坐标。
下表是真正的**仿真接触力**，不是上述力矩等效值；控制模型和仿真机均为 14.705035 kg。

| 指标 | 原参数：过渡 0.20 s、抬脚 0.08 m | 最终候选：过渡 0.04 s、抬脚 0.04 m |
| --- | ---: | ---: |
| 第一组支撑腿，前 0–50 ms 平均 Fz | 79.1 N | 112.0 N |
| 第一组支撑腿，50–100 ms 平均 Fz | 110.0 N | 145.2 N |
| 第二组支撑腿，前 0–50 ms 平均 Fz | 80.3 N | 113.6 N |
| 第二组支撑腿，50–100 ms 平均 Fz | 113.5 N | 145.4 N |
| 两组对角离地测试指标 | 32.9 / 34.1 mm | 28.4 / 28.1 mm |
| 全段最大关节速度 | 2.39 rad/s | 3.23 rad/s |
| 全段最大施加关节力矩 | 20.20 Nm | 17.22 Nm |

原配置在初期仍由尚未离地的摆动腿承担部分负载，四脚实际总接触力没有同步降低到 79–80 N。
因此不能把该表的支撑腿子集合直接解释为整机总支撑力不足。
它验证的是指定支撑腿接管速度，不能独立证明实机跌落原因。

只缩短过渡到 0.04 s、保留 8 cm 抬脚时，仿真全段关节速度峰值约 5.88 rad/s；
同时把抬脚高度降至 4 cm 后降到约 3.23 rad/s。最终固化两个现有参数：

```text
model_settings.phaseTransitionStanceTime = 0.04
swing_trajectory_config.swingHeight = 0.04
```

单次摆腿窗口保持 0.45 s；质量、重力、KP=20/KD=5、力矩上限和 WBC 权重保留原值。
参数对连续踏步也生效。配置通过安装目录的符号链接直接读取，重启控制程序后生效。
