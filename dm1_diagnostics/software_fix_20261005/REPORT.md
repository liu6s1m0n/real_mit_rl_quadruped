# DM1 软件修复验证（2026-10-05）

## 当前修改

- 2号 TROT：0.5秒周期、50%支撑；3号 STATIC_WALK：1.0秒周期、80%支撑。MPC接触表、步态调度器和提示保持一致。
- 真机与仿真共享步态选择：W/S/A/D/Q/E沿用2/3的选择，空格停止不覆盖选择。默认TROT；历史TROT_WALK枚举和控制器保留，键盘方向入口不再自动切到它。
- MIT命令先在控制线程完成整体校验与力矩饱和，再以完整快照交给独立125Hz发送线程。每轮尝试全部12台电机，某台发送失败不跳过其余电机；每帧间隔250微秒，下一轮继续尝试。
- 按用户要求：通信故障（含0x0D）、反馈/控制失败、发送异常均不因超时自动失能，持续重发最近一组有效命令。移除3秒失败计数退出；未引入100毫秒失能策略。
- 电机损坏风险保护、明确的0/Esc/Ctrl+C退出仍保留。键盘线程异常退出时读取电机故障、保持旧命令，不生成新动作。启动前使能校验保留。
- pause等待在途发送完成，停机先join发送线程再关闭硬件，避免关闭后继续写CAN。

## 验证

全量编译成功。12组定向测试共102项：101通过、1失败。

通过项目含：50%/80%接触比例和来回切换、方向键保留选择、MIT力矩饱和、单台发送失败仍尝试12台、控制线程阻塞50毫秒期间持续发送、旧命令持续保持、传输异常重试、0x0D通信失败超过原3秒门限仍续发、真实电机故障失能、主动停止后不再发送。两种原地步态、原地切换及历史MPC方向测试通过。

新增 SelectedGaitsKeepBalanceWithDirectionKeys 测试失败：用默认方向速度执行所选步态时，TROT前进/左右移及STATIC_WALK后退/左右移出现姿态或回退问题。它验证的是新的“方向键沿用步态”组合，不能用原60% TROT_WALK方向测试通过来代替。失败断言保留，未放宽阈值；试验性的降速/落脚公式变更均未保留。

ThreadSanitizer未完成运行：当前环境报告unexpected memory mapping；没有据此声称无线程竞争。线程发送/暂停/恢复/退出已做功能测试。

两处本地安装目录随源码更新。没有连接/使能/启动真实电机。软件的持续重发不等于物理总线必然送达，电机固件自身保护也没有被解除。因此不能将当前状态表述为真机红灯问题已完全消除。
